# claude-discord

A Claude Code plugin that bridges a Discord bot to a Claude Code session. Inspired by [`claude-plugins-official/discord`](https://github.com/anthropics/claude-plugins) but rewritten from scratch under MIT, with our own product requirements developed via the [BMAD-METHOD](https://github.com/bmad-code-org/BMAD-METHOD) workflow.

## Status

Early planning. Product brief, PRD, and architecture are being driven through BMAD's analyst → PM → architect phases. See open issues for the current roadmap.
